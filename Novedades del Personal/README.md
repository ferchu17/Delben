# Novedades del Personal

Proyecto independiente de Planilla de Novedades del Personal.

## Objetivo

Desarrollar y mantener el módulo de Novedades del Personal de forma aislada, archivo por archivo, antes de implementar cambios en Google Apps Script.

## Regla de trabajo

- Cada archivo `.gs` o `.html` se mantiene completo y listo para reemplazar.
- No se modifican otros módulos del repositorio.
- No se inventan reglas de negocio: se conservan las reglas confirmadas del sistema actual.
- Los cambios se prueban antes de pasar a Google Apps Script.
